# Erdenael

Sacoche Duplicatrice - version prete pour Render.

## Deploiement rapide

1. Cree un nouveau repo GitHub.
2. Mets uniquement le contenu de ce dossier dans le repo.
3. Sur Render, clique sur New > Blueprint.
4. Connecte ce repo.
5. Render lit `render.yaml` et deploie le site.

URL finale attendue :

`https://ton-service.onrender.com/erdenael`
